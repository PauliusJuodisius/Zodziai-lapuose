# Pasakos

```

  0_ruosinys.md          – autoriaus ruošinys, pažodžiui
  1_planas.md            – trumpas planas
  2_isplestas_planas.md  – išplėstas planas su pasaulio taisyklėmis
  3_tekstas.md           – galutinis tekstas
  4_patikra.md           – savikontrolės sąrašas
```
